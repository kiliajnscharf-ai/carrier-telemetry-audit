
## Zielsetzung und Oeffentlichkeitsnachweis
Dieses Repository dient der unabhaengigen, revisionssicheren Dokumentation der realen Mobilfunkversorgung am Standort Bad Pyrmont.
Alle Messreihen (Durchsatz, Latenz, Zell-Identifikatoren) werden automatisiert erhoben, um Netzbetreibern, Pruefbehoerden und der Oeffentlichkeit eine transparente Datengrundlage bereitzustellen.
